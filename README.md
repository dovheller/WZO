# קֶשֶׁר · CRM קהילתי — אב-טיפוס

מערכת ניהול קהילות יהודיות בתפוצות, על תשתית ההסתדרות הציונית העולמית (WZO).
אב-טיפוס להדגמה — לא מערכת עובדת. דף אינטראקטיבי אחד עם ארבעה מסכים.

> **Demo live:** https://dovheller.github.io/WZO

## מערכת מותג

נצמדה לטוקנים שחולצו מאתר WZO הרשמי:

**צבעים**
- כחול ציוני `#1E4382` · כחול כהה `#1C3B77` · כחול עמוק `#151D66`
- תכלת בהיר `#A7E3F6` · תכלת `#18A1DA`
- **ענבר `#D88B00`** — חתימת המותג, כל ה-CTAs
- חרדל `#DBA62A` · קרם `#FAF9F5` · גבולות `#DDDDDD`

**טיפוגרפיה**
- **Assistant** (ExtraBold 800) — כותרות הירואיות
- **Heebo** (400/500/600) — גוף טקסט
- שתי המשפחות מ-Google Fonts; חלופות חופשיות לפונטי המותג Almoni Neue ו-Hadassah Friedlaender.

**שפה ויזואלית**
- RTL מלא · ניגוד כחול-עמוק / ענבר
- דפוס מנוקד עדין ברקעי באנרים, חצאי מגן-דוד דקורטיביים
- אייקונים line-icon פשוטים בלבד

## הפעלה

הכל סטטי. אפשר לפתוח את `index.html` בדפדפן ישירות, או להרים שרת מקומי:

```bash
python3 -m http.server 8000
# פתח http://localhost:8000
```

לפרסום ב-GitHub Pages: פשוט תעלה את כל הקבצים לשורש ה-repo ותפעיל Pages על branch `main`.

---

## מבנה הקבצים

```
.
├── index.html          # נקודת כניסה — טוען פונטים, React, וה-JSX
├── styles.css          # כל ה-CSS — טוקנים + מסכים + responsive
├── icons.jsx           # ספריית line-icons (window.I)
├── kiosk.jsx           # מסך 1 — לוח קהילתי
├── member.jsx          # מסך 2 — מסך החבר
├── admin.jsx           # מסך 3 — ניהול קהילה
├── super.jsx           # מסך 4 — מסך-העל WZO
├── app.jsx             # shell, ניווט בטאבים, footer
└── README.md
```

הקבצים מסונכרנים דרך `window.*` (כל קומפוננטה רושמת את עצמה ל-window כדי שתהיה זמינה ב-app.jsx).

## רספונסיביות

- **דסקטופ** (1025px+) — תצוגה מלאה
- **טאבלט** (≤ 1024px) — KPI לשני טורים, גרידים מתקפלים
- **מובייל** (≤ 720px) — טור אחד, sidebar של ה-admin הופך לרצועה גוללת, hero-banners מתקפלים אנכית
- **טלפון קטן** (≤ 380px) — KPI לטור יחיד

## תכונות עיקריות שכבר ממומשות (כ-Demo)

- ניווט מלא בין 4 המסכים בטאבים
- הרשמה/ביטול לאירועים במסך החבר (state חי)
- טופס תרומה אינטראקטיבי במסך הגבאי (סכום/חבר/הקדשה ניתנים לעריכה)
- 22 סיכות עיר על מפת העולם, מיקום מחושב מ-lat/lng
- מבזקים גוללים בקיוסק (CSS animation, לא JS)
- ללא localStorage · ללא קריאות רשת חיצוניות (מלבד Google Fonts ו-CDN של React)

## ערות פיתוח עתידי

המערכת תושק כדו-לשונית: **עברית 🇮🇱 / English 🇬🇧** — RTL ↔ LTR מלא.
התשתית Multi-Tenant: כל קהילה היא עולם נפרד, מעל תשתית אחת של ההסתדרות.

לגרסת ההמשך כדאי לעצב:
- מצב כהה לקיוסק (תצוגת לילה / שבת)
- וריאציה למסך-העל עם פיצול לפי יבשת
- מסך mobile-first ייעודי לחבר הקהילה
- ספריית תבניות הפעלה מורחבת (חגי תשרי, ימים נוראים, צום, ל"ג בעומר)
