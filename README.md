## 📂 מבנה התיקייה

```
release/
├─ Kesher v2.html        ← הקובץ הראשי. עצמאי. לחיצה כפולה ופותח.
├─ README.md
└─ dev/                  ← קוד-מקור רב-קבצי לפיתוח. לא חובה להעלות לפרודקשן.
   ├─ index.html
   ├─ styles.css
   ├─ i18n.jsx
   ├─ icons.jsx
   ├─ features.jsx       ← רכיבי v2: גמ"ח, אבות ובנים, ניקוד והגרלות, עליות, ניהול עסקים
   ├─ kiosk.jsx
   ├─ member.jsx
   ├─ admin.jsx
   ├─ super.jsx
   └─ app.jsx
```

## 🚀 הפעלה

### דרך 1 — קובץ עצמאי (מומלץ לדמו / שיתוף)
```
פתח את  Kesher v2.html  בלחיצה כפולה.
```
כל ה-CSS וכל ה-JSX מוטמעים בקובץ. React ו-Babel נטענים מ-CDN (דורש אינטרנט בפעם הראשונה; לאחר מכן הדפדפן מטמן). אין fetches לקבצים מקומיים — לכן עובד גם מ-`file://` ללא שרת.

### דרך 2 — סביבת פיתוח (לעריכה)
```
cd release/dev
python3 -m http.server 8000
# ואז: http://localhost:8000
```
או כל שרת סטטי אחר (`npx serve`, `live-server` וכו').
